## Proposed production comparison shape — not implemented

1. Capture a session-scoped **actual node reference**, layer mixin and its backing `layerAsRefTarg` reference. Require readable backing-target identity and same-reference plus `getHandleByAnim`/`getAnimByHandle` round-trip. A handle by itself is not identity, a layer name is never identity, a mixin is not passed as a MaxObject, and no persistence/reuse guarantee is inferred. On replay, read `node.layer` anew, obtain the backing target anew, and compare **both** target reference and handle against the retained exact witness. Anything unreadable/ambiguous/changed refuses before geometry evaluation.
2. In addition, copy the **name as state**, not authority. Enumerate and require the exact supported property-name sets/types; recursively detach scalar values, including RGBA and finite numeric types. Here the evidence supports a *candidate* 31 scalar layer-interface fields + 18 nested GI fields and, separately, backing-reference fields including `#degrade`; the mixin and backing-reference non-scalars must be handled explicitly. Exact property sets do not prove undocumented native or renderer/plugin completeness. Unknown class, enumeration drift, missing required name, thrown getter, nonfinite value, unsupported interface or nested state => **UNSUPPORTED**, never `undefined == undefined`, never `absent == absent`, and never stringified-reference equality. Re-read/copy and compare exact typed values. Test each admitted mutation class; a single lock/GI/rename test cannot prove every field.
3. Explicitly address current-layer, parent and children, member node set, nested GI state and reference dependencies. Either compare calibrated, bounded, fully classified supported forms or strictly disallow them with proof. The default layer's manager/root dependencies are shared scene machinery; do not mistake all dependents for owned nodes or delete them. `getPropNames` is evidence of exposed fields, not proof of all hidden state, controllers or plugin extensions. Fail closed on foreign/unknown dependencies; establish what is allowed at first construction rather than blessing whatever happens to exist.
4. Identity proof and detached state are **separate**: same layer after rename should keep backing identity but differ in copied name; assignment to a distinct layer must differ even if all copied properties coincide. Identical-name replacement must differ by exact reference or be rejected as ambiguous; the candidates do **not** perform that more hazardous replacement test. Delete/recreate, handle reuse, undo/redo, save/load/merge/restart and external change notifications remain uncalibrated. No edit-history claim is made for change-and-perfect-revert.
5. Keep broad native mesh/specified-normal, modifier/controller descendant, scene/dependency and independent F01 gates independent. Until all are proven, retain the unconditional replay refusal. This layer design is not an implementable bypass of the current blocker.

## Candidate 02 — `02-owned-layer-candidate.ms` — NOT APPROVED TO RUN AS-IS

This **long design scaffold** is not approved for execution as-is: ~23 KiB of source plus many snapshot reads may violate the short-call budget, and neither parsing nor timing is known. It includes guarded comparisons for exact existing root/default reference, layer membership and dependents, typed copied default+GI+backing values (including `#degrade`) and property-set drift, existing current layer, path, mm/1, time, selection, subobject level and census. * Layer-only controls: compare original vs distinct owned interface and backing refs in both directions and handles; same-layer lookup alias; detached clean snapshot; actual lock change/restore; actual nested GI boolean change/restore; actual owned-layer rename/restore with backing identity stable and copied-name mismatch. * Cleanup is a separate guarded attempt even after a throw. Node deletion uses only the exact retained node and handle after live census, parent/children, material/base/dependency and layer proofs. Layer deletion uses the exact constructor-returned layer plus its exact backing reference/handle, unchanged reviewed dependencies, verified no nodes/children, non-current state, identity-checked name lookup and restored owned state; the name is only the required deletion API argument after identity proof.
